# Readdy への差し替え手順

現行サイトは Readdy で作成・公開されているため、**Readdy のコードエディタで
中身を差し替える**のが最短です。ドメイン・SSL・ホスティングはそのままで、
DNSの変更も不要です。

Readdy の画面右パネルにある **「Code」タブ**を開くと、ファイル一覧と
ソースコードが編集できます。保存するとプレビューに即反映されます。

---

## ステップ1：プロジェクトの種類を確認する

Code タブを開き、ファイル一覧に何があるかを確認してください。

| 見えるファイル | 種類 | 使うファイル |
|---|---|---|
| `App.tsx` や `src/` フォルダがある | React | このフォルダの `App.tsx` |
| `index.html` だけで `src/` がない | 素のHTML | 1つ上の階層の `index.html` |

以下、それぞれの手順です。

---

## ステップ2A：React（`App.tsx` がある場合）

1. `readdy/App.tsx` の中身を**全文コピー**し、Readdy の `App.tsx` に
   **全て上書き**で貼り付けます。
2. 冒頭の3つの定数を確認・変更します。

   ```ts
   const LAWYER_PHOTO = "/lawyer.jpg";              // 弁護士写真のURL
   const LINE_URL = "https://lin.ee/Mc3bGjk";       // 設定済み
   const GADS_CONVERSION_LABEL = "";                // 広告のコンバージョンラベル
   ```

   `LAWYER_PHOTO` は、**現行LPで既に使っている写真のURL**を指定するのが
   確実です。現行ページを右クリック →「画像アドレスをコピー」で取得できます。

3. `index.html`（プロジェクト直下のもの）の `<head>` 内に、
   `readdy/head-tags.html` の中身を反映します。タイトル・説明文・OGP設定です。

4. Tailwind を使っているプロジェクトでも、そのまま動きます。
   このLPのCSSは `<style>` タグで自己完結しており、Tailwind と競合しません。

**動作確認済み**：React 19 + Vite + TypeScript（strict）でビルドが通り、
素のHTML版と同一の表示になることを確認しています。

---

## ステップ2B：素のHTML（`src/` がない場合）

1つ上の階層の `index.html` の中身をそのまま貼り付けてください。
ただし `assets/css/style.css` と `assets/js/main.js` も同じ構成で
アップロードする必要があります。

ファイルを分けられない場合は、チャットでお送りした
**1ファイル完結版のHTML**（CSS・JS・画像をすべて埋め込み済み）を
そのまま貼り付けてください。これが最も確実です。

---

## ステップ3：差し替え前に必ずやること

### 計測タグを引き継ぐ（最重要）

現行サイトの `<head>` に入っている Google タグ（`gtag.js`）を、
**必ず新しいページにも残してください。**

これを忘れると、差し替えた瞬間に**広告のコンバージョン計測が止まります。**
広告を配信したまま差し替えるので、ここが一番の事故ポイントです。

現行ページで確認する方法：ブラウザでページを開き、右クリック →
「ページのソースを表示」→ `gtag` または `googletagmanager` で検索してください。
見つかったタグをそのまま新しい `index.html` の `<head>` に入れます。

タグを入れたら、`App.tsx` の `GADS_CONVERSION_LABEL` に
コンバージョンラベル（`AW-1234567890/AbCdEfGh` の形式）を設定してください。
設定すると、LINEボタンのクリックがコンバージョンとして送信されます。

### リンク先を実在するURLに直す

現在は仮のパスが入っています。Readdy 側の実際のページURLに変更してください。

- `/contact/` … お問い合わせフォーム（2箇所）
- `/privacy/` … プライバシーポリシー（フッター）

該当ページがない場合は、そのリンクごと削除しても問題ありません。

### バックアップを取る

Readdy にバージョン履歴があれば、差し替え前の状態を復元できるか
確認しておいてください。反応が落ちた場合に戻せます。

### コラム記事を消さない

今回の改修でLPからコラムへの導線は外しましたが、記事自体はSEOの資産です。
**トップページのみを差し替え、コラムのURLはそのまま残してください。**

---

## ステップ4：公開後の確認

- スマホとPCの両方で表示を確認する
- LINEボタンをタップし、友だち追加画面に飛ぶか確認する
- スマホで少し下にスクロールし、画面下にLINEボタンが出るか確認する
- 翌日、Google広告の管理画面でコンバージョンが計測されているか確認する
- Search Console でトップページのインデックス状況を確認する

---

## うまくいかない場合

Readdy のコードエディタが編集を受け付けない、または貼り付けても
表示が崩れる場合は、AIチャット側から指示する方法もあります。
その場合はご連絡ください。このLPの内容を Readdy のAIに渡すための
指示文を用意します。

なお Readdy は有料プランでコードのエクスポートに対応しています。
将来的に Readdy から離れる場合は、このリポジトリの `index.html` +
`assets/` をそのまま任意のサーバーに置けば動きます。
