# Readdy への差し替え手順

いただいたプロジェクト（Next.js 15 / App Router）に合わせて作成しました。
**差し替えるファイルは `app/page.tsx` の1つだけ**です。

`readdy/page.tsx` の中身を全文コピーし、Readdy のコードエディタで
`app/page.tsx` に**全て上書き**してください。それだけで完了します。

---

## ファイルサイズについて

Readdy のコードエディタには「1ファイル1500行・180000文字」という上限があります。
`readdy/page.tsx` は **1,372行 / 89,227文字**で、両方とも上限内に収めてあります。
保存時に容量の警告は出ません。

上限に収めるため、CSS部分は esbuild で圧縮しています（1,089行 → 366行）。
圧縮前後で描画が変わらないことは、計算済みスタイル43項目の比較と
ページ全体の画素比較で確認済みです。

読みやすい形のCSSは `assets/css/style.css` に残してあります。
色や余白を調整したい場合はそちらを直し、再度圧縮して差し替えるのが確実です。

---

## layout.tsx は触らなくて大丈夫です

プロジェクトを確認したところ、重要な仕組みはすべて `app/layout.tsx` 側に
入っていました。`app/page.tsx` だけを差し替えれば、以下はそのまま維持されます。

| 仕組み | 状態 |
|---|---|
| GA4（`G-51RZ775L54`） | そのまま有効 |
| Google広告（`AW-17931041617`） | そのまま有効 |
| LINEクリックのコンバージョン計測（`line-cv`） | **そのまま有効** |
| 画面下の固定CTA（`FloatingCTABar`） | そのまま表示 |
| コラム記事（`/column`） | 影響なし |
| お問い合わせフォーム（`/contact`） | 影響なし |

**当初いちばん心配していた「差し替えでコンバージョン計測が止まる」問題は、
このプロジェクトでは起きません。** タグが layout.tsx にあるためです。

とくに `line-cv` のスクリプトは、`lin.ee` を含むリンクのクリックを
すべて拾ってコンバージョンを送る作りになっています。新LPのLINEボタンは
6箇所すべてこの条件を満たすので、**追加の設定なしで計測されます。**

---

## プロジェクトに合わせて調整した点

新LPは元々1枚のHTMLとして作ったため、そのまま入れると既存の仕組みと
ぶつかります。以下は調整済みです。

- **自前の固定CTAを削除。** `FloatingCTABar` と二重に表示されるため。
  画面下のCTAは既存のもの（LINE＋電話の2分割）がそのまま使われます。
- **`body` の下部余白を削除。** layout.tsx に `pb-16` があり二重になるため。
- **コンバージョン送信のコードを入れていない。** `line-cv` と重複して
  二重計上になるため。計測は既存の仕組みに任せています。
- **フォントを `--font-noto-serif-jp` / `--font-noto-sans-jp` から参照。**
  layout.tsx で読み込み済みの Noto Serif JP / Noto Sans JP を使います。
- **弁護士写真は既存のURLを指定。** 新たなアップロードは不要です。
- **プライバシーポリシーへのリンクを削除。** 該当ページが無いため。
  ページを作った場合は、フッターに追加してください。
- **お問い合わせリンクを `/contact` に統一。**（末尾スラッシュなし）

**動作確認済み**：いただいたプロジェクトに実際に組み込み、
Next.js 15.3.2 の開発サーバーで表示を確認しました。
固定CTAが重複しないこと、既存のフォントが適用されること、
横スクロールが出ないことをPC・スマホ幅で確認しています。

## あわせて直したほうがよい箇所（任意）

### 1. 構造化データの料金が古いままです（推奨）

`app/layout.tsx` の FAQ 構造化データ（`id="faq-schema"`）に、
**新LPと矛盾する料金**が書かれています。Googleは構造化データも読むため、
表示内容と食い違ったままにしない方が安全です。

以下の2箇所を置き換えてください。

**置換1**（複数社の料金）

```
1社目は33万円、2〜4社目は1社あたり16万5000円、5社目以降は追加着手金をいただきません。
```
↓
```
1社目は33万円、2社目以降は半額の16万5000円、6社目以降は追加着手金をいただきません。
```

**置換2**（分割払い）

```
着手金については3回払いまで対応しております。お支払いが困難な場合は、まずはご相談ください。お客様の状況に応じて、可能な限り柔軟に対応いたします。
```
↓
```
クレジットカードでのお支払いに対応しており、ご利用のカード会社の分割払いをご利用いただけます。回数や手数料は各カード会社の規定によります。お支払いが困難な場合も、まずはご相談ください。
```

### 2. OGPのURLが別ドメインを指しています（軽微）

`app/layout.tsx` の `openGraph.url` が `https://tomida-shimaoka.com` に
なっています。このサイトは `https://tomidashimaoka-torrent.com` なので、
SNSでシェアされた際の表示を正しくするなら修正しておくとよいです。

### 3. ページタイトル・説明文はそのままで問題ありません

`metadata` のタイトルは検索キーワードを含んだ良い形になっているので、
**変更しないことをおすすめします。**タイトルを変えると検索順位が
動く可能性があり、広告とは別に不利益が出かねません。

## 注意：既存のビルドエラーについて

差し替えとは無関係ですが、このプロジェクトは現状 `next build` が
型エラーで失敗します。**新LPを入れる前から発生している問題**で、
元の `app/page.tsx` に戻しても同じエラーが出ることを確認済みです。

```
app/column/[id]/page.tsx
Type error: Type '{ params: { id: string; }; }' does not satisfy the constraint 'PageProps'.
```

Next.js 15 から `params` が Promise になった仕様変更によるものです。
Readdy 側の公開処理が型チェックを通しているかは分かりませんが、
**公開時にビルドエラーが出た場合、新LPが原因ではありません。**
その場合はご連絡ください。修正方法をお伝えします。

## 差し替え後の確認

- スマホとPCの両方で表示を確認する
- LINEボタンをタップし、友だち追加画面に飛ぶか確認する
- スマホで画面下の固定CTA（LINE＋電話）が表示されるか確認する
- `/contact` と `/column` が今まで通り開くか確認する
- 翌日、Google広告の管理画面でコンバージョンが計測されているか確認する

差し替え前に、Readdy のバージョン履歴から元の状態に戻せるか
確認しておくと安心です。
