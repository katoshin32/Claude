# 週次レポートの作成

対象期間: $ARGUMENTS （指定がなければ今日から遡って7日間）

以下の手順で週次レポートを作成してください。各ソースは接続済みの MCP を使います。

1. **予定の集計**: Google Calendar から対象期間の予定を取得し、会議・作業時間の概要を把握する。
2. **コミュニケーション**: Gmail から対象期間に送受信した重要なスレッドを検索し、
   要対応・完了した案件を抽出する（本文の全文転記はせず要点のみ）。
3. **開発・タスク進捗**: GitHub から自分に関係する PR / Issue の動き、Asana から
   担当タスクのステータス変化を集計する。
4. **レポート生成**: 次の構成でまとめる。
   - ✅ 今週やったこと（成果ベースで簡潔に）
   - 🚧 進行中・ブロッカー
   - 📅 来週の予定・優先事項
   - 📝 共有事項 / 要相談
5. **保存**: 完成したレポートを Notion に新規ページとして保存する。タイトルは
   「週次レポート YYYY-MM-DD」。保存後、ページの URL を報告する。

注意:
- 不確かな情報は推測で埋めず「要確認」と明記する。
- 外部へのメール送信や共有は行わず、Notion への保存までで止める。
