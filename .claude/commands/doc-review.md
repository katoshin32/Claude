# ドキュメントレビュー

対象: $ARGUMENTS

対象ドキュメントを読み込み（リポジトリ内パス・Notion ページ・Drive ファイルのいずれか）、
`doc-reviewer` サブエージェントを使って品質レビューを行ってください。

レビューは次の観点で行い、**指摘ごとに「該当箇所 → 問題 → 修正案」**の形で返す:

1. **正確性**: 事実誤認・古い情報・矛盾がないか。
2. **明確さ**: 読み手にとって曖昧／多義的な表現、主語の欠落。
3. **構成**: 見出し階層、情報の順序、重複。
4. **網羅性**: 前提・手順・例外ケースの抜け。
5. **対象読者への適合**: 専門用語の説明過不足、トーン。

最後に、重大度（高/中/低）順に並べた要約と、まず直すべき上位3点を提示する。

注意: 元ドキュメントを勝手に書き換えない。修正は提案にとどめ、適用は私の指示を待つ。
