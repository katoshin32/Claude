# 受信トレイのトリアージ

対象: $ARGUMENTS （省略時は未読の直近20件）

Gmail を使って受信メールを整理してください。**送信は一切行わず、下書きとラベル付けまで**で止めます。

## 手順

1. 対象条件でスレッドを検索し、各スレッドを次のカテゴリに分類する:
   - 🔴 要対応（自分の返信・判断が必要）
   - 🟡 要確認（読むべきだが即時対応は不要）
   - 🟢 参考・通知（アクション不要）
   - ⚪ ノイズ（広告・自動通知など）

2. 既存のラベル体系を確認し、各スレッドに適切なラベルを付ける
   （新規ラベルが必要なら作る前に提案する）。

3. 🔴 要対応のものには、返信の**下書き（draft）**を作成する。
   - 簡潔・丁寧・日本語を既定とする。
   - 不明点や判断が必要な箇所はプレースホルダ `【要確認: …】` を残す。

4. 最後に「要対応リスト」を重要度順に提示し、作成した下書きの件名を一覧する。

注意: メール送信・スレッドの削除・アーカイブは行わない。すべて私が最終確認する前提。
