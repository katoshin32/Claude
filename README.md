# トレントLP 改修版

冨田・島岡法律事務所 トレント案件LP（`tomidashimaoka-torrent.com`）の改修版です。
静的ファイルのみで構成しており、ビルド不要でそのまま公開できます。

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/lawyer.jpg   ← 現行LPからの複製。元データに差し替えてください
readdy/
  README.md             ← Readdy への差し替え手順
  page.tsx              ← app/page.tsx に上書きするファイル
```

**現行サイトは Readdy（Next.js 15 / App Router）で公開されています。
差し替えは `app/page.tsx` を1つ入れ替えるだけです。手順は
[`readdy/README.md`](readdy/README.md) を参照してください。**

上の `index.html` + `assets/` は、Readdy を離れて任意のサーバーで
公開する場合や、内容を確認する場合に使える単体版です。

弁護士写真は、現行LPの画面を取り込んだものを暫定的に入れてあります。
表示確認には使えますが解像度が足りないため、公開前に元の画像ファイルに
差し替えてください（推奨 800×1000px 前後）。

---

## 公開前に差し替えが必要な3項目

| # | 対象 | 場所 | 現在の値 |
|---|---|---|---|
| 1 | Google広告コンバージョンラベル | `assets/js/main.js` の `CONFIG.gadsConversionLabel` | 空（未送信） |
| 2 | 弁護士写真 | `assets/img/lawyer.jpg` | 現行LPから複製した低解像度版（700×875） |
| 3 | フォームURL | `index.html` の `href="/contact/"` | 仮パス |

いずれも単体版（`index.html`）を別サーバーで使う場合の話です。
Readdy への差し替え（`readdy/page.tsx`）では、3項目とも対応済みで作業は不要です。

LINE友だち追加URL（`https://lin.ee/Mc3bGjk`）は設定済みです。変更する場合は
以下のコマンドで一括置換できます。

```bash
sed -i 's|https://lin.ee/Mc3bGjk|新しいURL|g' index.html assets/js/main.js
```

HTMLの `href` にもURLを直書きしてあるため、JavaScriptが読み込まれない環境でも
LINEボタンは機能します。`CONFIG.lineUrl` はJS側からの一括上書き用です。

GA4のタグ（`gtag`）をページに設置すると、以下のイベントが自動で送信されます。
未設置でもエラーにはなりません。

- `line_friend_add` — LINEボタンのクリック（`cta_position` でページ内のどの位置か判別可能）
- `tel_tap` — 電話番号のタップ
- `faq_open` — 開かれたFAQ（どこで迷っているかの把握用）

実際のサイトへの差し替えは [`readdy/README.md`](readdy/README.md) を参照してください。

## 現行LPからの主な変更点

### 1. CTAをLINEに統一した

現行LPは、ヒーローはLINE、中間と最下部はウェブフォーム、ヘッダーはフォームと電話、
とボタンがバラバラでした。本文で「まずはLINEで」と繰り返しながら、
最後まで読んだ最も温まった読者をフォーム入力に送っていた状態です。

改修版では全6箇所の第一CTAをLINEに統一し、フォーム・電話は最下部の第二選択肢に
格下げしました。スマホではファーストビューを過ぎた時点で画面下に固定LINEボタンが出ます。
広告のコンバージョンを「LINE友だち追加」で計測する方針とも整合します。

### 2. 料金は「1社あたり33万円」だけを前面に出した

現行LPは料金セクションがページ後半（FAQより下）にあり、「成功報酬0円」の記載が
ありませんでした。隣に「成功報酬33万円〜」の訴訟プランが並んでいるため、
標準プランでも成功報酬を取られるように読める状態でした。

改修版では、ファーストビューに `着手金33万円（1社あたり）` と `成功報酬・追加費用0円`
の2枚を配置し、料金セクションを実績・FAQより前に移動しました。

相談に来られる方のほとんどは1社からの請求です。まずこの層を取りこぼさないことを
最優先とし、**総額の上限額は前面に出していません**。「最大99万円」という数字は
金額の大きさに身構えさせてしまうため、注記の1行にとどめています。

| 対応する社数 | 着手金（税込） |
|---|---|
| 1社目 | 33万円 |
| 2社目以降 | 半額の 16万5,000円 |
| 6社目以降 | 追加着手金なし |

複数社対応は「万が一の場合の備え」として、料金カードの下に副次的に置いています。

あわせて、示談金・和解金が弁護士費用とは別であること、実費・訴訟対応が別途であることを
料金表の直下に明記しました。ここが曖昧だと、後の誤解や日弁連の業務広告規程・
景表法上の問題につながるためです。

### 3. 解決実績の主役を「0円」から「減額和解」に変えた

現行LPは0円事例が3枚、減額和解が1枚という構成でした。これは、
今回のターゲット選定と逆行します。「0円にできる」を前面に出すと、
遠ざけたい「過剰請求だ、踏み倒したい」層を集め、
「多少の支払いは覚悟している」本来のターゲットには
「0円にならなければ失敗」という誤った期待を与えてしまいます。

改修版では「88万円→8万円」を大きく主役に据え、「150万円→50万円・約1ヶ月で和解」を
それに続けました。0円事例は請求根拠に疑問があった事案という文脈を添えて補助的に
並べています。冒頭に「すべての案件が0円になるわけではありません」と明記しました。

**「200万円→0円（名誉毀損・刑事告訴・捜索まで発展）」の事例は削除しました。**
トレント案件ではないうえ、「捜索」という語がこの不安層を過度に怯えさせるためです。
掲載する場合は、トレント案件とは別枠に分けることをおすすめします。

### 4. 「お任せいただける」ことを専用セクションで見せた

「お願いすること（3項目）」と「弁護士がすること（7項目）」を左右に並べ、
依頼後の役割分担を一目で分かるようにしました。競合サイトの「知識を授けます」型と
最も差がつく部分であり、丸投げ需要への直球の回答になります。

その下に、実際のLINEのやり取りをもとにした再現を置きました。
「送ったら何が起こるのか分からない」という不安を消すためのものです。

文面は実際にやり取りされたものをそのまま使っていますが、以下は加工しています。

- 相談者のお名前・呼びかけ（「◯◯様」）はすべて削除
- 具体的な通信事業者名は「プロバイダ」に置き換え
- 冗長な部分（「見辛いなどありましたら撮り直します」等）を省略

「再現イメージ」である旨に加えて「ご本人が特定されないよう加工した」ことを
明記しています。実在の依頼者のやり取りを掲載する以上、
ご本人の同意が取れているかは念のためご確認ください。

### 5. 「責めません」を上部に移した

現行LPでは、この層に最も刺さる「反省の気持ちを持ちながらも、法的に妥当な解決を
求めることは正当な権利です」という趣旨のメッセージが、ページ後半の弁護士紹介に
埋もれていました。改修版では2セクション目に独立した枠として配置しています。

なお、匿名相談は不可とのことでしたので「匿名OK」とは書かず、
代わりに守秘義務・家族や勤務先へ連絡しないことを前面に出し、
本人確認が必要である旨を注記しました。

### 6. 情報を増やす導線を絞った

FAQのタブ切り替え（基本／手続き／費用／その他）を廃止し、
不安の大きい順にフラットな9問へ再構成しました。このターゲットはタブを切り替えて探しません。
「家族や職場に知られませんか」「放置したらどうなりますか」「すぐにお金が用意できません」が
上位に来るようにしています。

ヒーローのコラム誘導リンクとナビの「コラム」も外しました。読者を教育するほど
「自分でやろう」に流れるため、今回の戦略ではLPからコラムへの導線は転換の漏れ穴になります。
コラム自体はSEO資産として別途残し、LPからは切り離す想定です。

### 7. コピー全体を「寄り添い」のトーンに統一した

ページ全体を、こちらから不安を言語化して煽るのではなく、
安心感を先に渡す書き方に揃えています。

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| 見出し | 調べるのは、もう終わりにしませんか。／あとは、弁護士が全部やります。 | まずは、ご安心ください。／あとは、すべてお任せください。 |
| 共感セクション | 「放置していい」「すぐ払え」——調べるほど、分からなくなります。 | 同じご相談を、数多くお受けしています。 |
| 役割分担 | あなたがすることは、書類の写真を送ることだけ。 | お願いするのは、書類の写真を送っていただくことだけ。 |
| 最終CTA | 回答期限が来る前に、まずは書類を見せてください。 | ひとりで抱えず、まずはご相談ください。 |

「調べるな」と読者の判断を遮る表現、「あなたは何も分からなくていい」と受け取られ得る
表現を排し、依頼するかどうかの判断は読者に委ねる書き方にしています。
共感セクションのチェックリストも6項目から4項目に減らし、
不安を数え上げる印象を弱めました。

### 8. 分割払いの記載を実態に合わせた

「3回払いまで対応可能」という現行の記載を、
「ご利用のカード会社の分割払いをご利用いただけます（回数・手数料は各カード会社の規定によります）」
に変更しました。あわせて、流れのステップ3を「着手金のお振込み」から
「着手金のお支払い（カード可）」に修正しています。

## セクション構成

1. ファーストビュー（見出し＋料金3枚＋LINE CTA）
2. 共感 ＋「私たちは、あなたを責めません」
3. 丸投げできる（役割分担＋LINEトーク再現）
4. 料金
5. 解決実績
6. 解決までの流れ（4ステップ）
7. 弁護士・事務所紹介
8. よくあるご質問（9問）
9. 最終CTA
10. フッター／スマホ固定CTA

Readdy版（`readdy/page.tsx`）では、10の固定CTAは既存の `FloatingCTABar` に任せるため
含めていません。

## 技術メモ

- Webフォントは使わず端末内蔵の明朝・ゴシックを指定しています。広告LPは表示速度が
  そのまま品質スコアと獲得単価に響くため、外部リクエストをゼロにしています。
  ブランドフォントを厳密に合わせたい場合はGoogle Fontsに差し替えてください。
- FAQとプラン詳細は `<details>` で実装しているため、JavaScriptなしでも開閉します。
- 日本語は語中でも改行されるため、見出しは文節ごとに `inline-block` で包み、
  フォントサイズを `clamp(1.5rem, 6.3vw, 2.45rem)` にして
  「全部やりま／す。」のような割れ方を防いでいます。
- 構造化データ（LegalService）を埋め込んでいます。

### 表示確認済み

Chromium にて 360 / 390 / 430 / 768 / 1024 / 1280 / 1440px の7幅で確認済み。
全幅で横スクロールなし、見出しの文節割れなし、JSエラーなし。
スマホ固定CTAの出入り、JavaScript無効時のLINEボタン動作も確認済みです。

## 要ご確認

- **LINEやり取りの掲載可否**：実在の依頼者とのやり取りをもとにしているため、
  ご本人の同意の有無をご確認ください（`index.html` の `.talk-demo`）。

  （「相手方の請求額の算定根拠を精査したうえで交渉し…」）はこちらで補いました。
  事実と異なる場合はご指示ください。他の事例の説明文も同様にご確認をお願いします。

## 今後の検討事項

- ファーストビューの見出しは、広告文言との一致度がクリック後の離脱率に効きます。
  広告見出しが「意見照会書」なら、LP側もその語で受けるパターンを別途用意して
  A/Bテストする価値があります。
- LINE公式アカウントの自動応答に「書類の写真を送ってください。弁護士が確認して
  ◯時間以内にご返信します」を設定しておくと、深夜の流入を取りこぼしません。
- 現行LPにあったコラムは、LPとは別URLでSEO流入の受け皿として維持し、
  コラム側からLPへ送る一方通行の導線にするのが今回の戦略と整合します。
