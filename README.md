# 冨田・島岡法律事務所 — トレント案件 ランディングページ

トレント（BitTorrent）による著作権侵害で**意見照会書・開示通知書**が届いた方に向けた、
冨田・島岡法律事務所（加藤 信 弁護士）集客用のシングルページ LP です。

- **技術**: 単一 HTML + Tailwind CSS v4（事前コンパイル済み）+ GSAP / ScrollTrigger
- **デザイン**: クリーム基調の温かみ × ネイビーの権威感 × テラコッタ／ゴールドのアクセント、LINE 相談は LINE グリーン
- **フォント**: 見出し = Shippori Mincho B1（明朝）／本文 = Noto Sans JP（Google Fonts）
- **対応**: レスポンシブ（375 / 768 / 1024 / 1440px）、キーボードフォーカス、`prefers-reduced-motion`、no-JS フォールバック

## ファイル構成

```
index.html          ← 配布用（自己完結・依存インライン化・219KB）。これ1枚で動きます
src/
  index.html        ← 編集用ソース（Tailwind クラス付き、外部参照）
  input.css         ← Tailwind 入力（@theme でカラー/フォント定義）
  styles.css        ← input.css をコンパイルした CSS
  app.js            ← アニメーション/FAQ/メニュー/受付ステータス
  vendor/           ← GSAP・ScrollTrigger（インライン化の元ファイル）
  build.cjs         ← ソースを index.html に結合するスクリプト
```

## デプロイ

`index.html` を任意の静的ホスティング（GitHub Pages / Netlify / Vercel / レンタルサーバ等）に置くだけです。
唯一の外部依存は Google Fonts のみ。オフラインでも（フォントがシステム代替になる以外は）動作します。

## 編集・再ビルド

1. `src/index.html`（本文）・`src/input.css`（色/フォント）・`src/app.js`（挙動）を編集
2. クラスやトークンを変えた場合は CSS を再コンパイル:
   ```bash
   npx @tailwindcss/cli -i src/input.css -o src/styles.css --minify
   ```
3. 配布用 `index.html` を再生成:
   ```bash
   node src/build.cjs
   ```
   `src/index.html` は `src/` 配下で直接プレビューも可能です。

## 差し替え・接続が必要な箇所（実運用前に）

| 箇所 | 現状 | 対応 |
|---|---|---|
| **相談CTA / LINE** | `href="#contact"` `#` のプレースホルダ | LINE 公式アカウント URL・相談フォーム URL に差し替え |
| **弁護士写真** | モノグラム（加）プレースホルダ | `#lawyer` の枠に実写真を配置 |
| **メディア「記事を読む」** | `#` リンク | 実記事 URL に差し替え |
| **プライバシーポリシー / 運営者情報** | フッターの `#` リンク | 各ページへ |
| **コラム** | ナビ項目（現状はメディア節へ誘導） | コラム一覧へ |

## 制作上の判断メモ

- **カウントダウン演出は入れていません。** 実サイト（tomidashimaoka-torrent.com）に該当要素がなく、
  この「落ち着いた安心感」のトーンに煽り演出は逆効果と判断し、代わりにヒーローへ
  **時間帯連動の受付ステータス**（電話受付 10:00–19:00 内外を JST で判定）と
  「Web 相談は 24 時間受付・原則 24 時間以内に返信」を配置しました。
  literal なカウントダウンが必要であれば差し替え可能です。
- **FAQ の回答文は、参考サイトに設問のみで回答が掲載されていなかったため、一般的な説明として当方で起草**しています。
  内容は必ず弁護士（事務所）でご確認・修正のうえ公開してください（セクション冒頭に注記済み）。
- 解決実績・料金・経歴・事務所情報は、いただいたサイト掲載テキストをそのまま反映しています。
  実績には「※匿名加工・結果を保証しない」旨の注記を掲載済みです。
