# トレントLP 改修版

冨田・島岡法律事務所 トレント案件LP（`tomidashimaoka-torrent.com`）の改修版です。
静的ファイルのみで構成しており、ビルド不要でそのまま公開できます。

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/lawyer.jpg   ← プレースホルダー。実物の写真に差し替えてください
```

---

## 公開前に差し替えが必要な4項目

| # | 対象 | 場所 | 現在の値 |
|---|---|---|---|
| 1 | LINE友だち追加URL | `assets/js/main.js` の `CONFIG.lineUrl` と `index.html` 内6箇所 | `https://lin.ee/XXXXXXX` |
| 2 | Google広告コンバージョンラベル | `assets/js/main.js` の `CONFIG.gadsConversionLabel` | 空（未送信） |
| 3 | 弁護士写真 | `assets/img/lawyer.jpg` | プレースホルダー画像 |
| 4 | フォームURL | `index.html` の `href="/contact/"` | 仮パス |

LINE URLは以下のコマンドで一括置換できます。

```bash
sed -i 's|https://lin.ee/XXXXXXX|実際のURL|g' index.html assets/js/main.js
```

HTMLの `href` にもURLを直書きしてあるため、JavaScriptが読み込まれない環境でも
LINEボタンは機能します。`CONFIG.lineUrl` はJS側からの一括上書き用です。

GA4のタグ（`gtag`）をページに設置すると、以下のイベントが自動で送信されます。
未設置でもエラーにはなりません。

- `line_friend_add` — LINEボタンのクリック（`cta_position` でページ内のどの位置か判別可能）
- `tel_tap` — 電話番号のタップ
- `faq_open` — 開かれたFAQ（どこで迷っているかの把握用）

## 現行LPからの主な変更点

### 1. CTAをLINEに統一した

現行LPは、ヒーローはLINE、中間と最下部はウェブフォーム、ヘッダーはフォームと電話、
とボタンがバラバラでした。本文で「まずはLINEで」と繰り返しながら、
最後まで読んだ最も温まった読者をフォーム入力に送っていた状態です。

改修版では全6箇所の第一CTAをLINEに統一し、フォーム・電話は最下部の第二選択肢に
格下げしました。スマホではファーストビューを過ぎた時点で画面下に固定LINEボタンが出ます。
広告のコンバージョンを「LINE友だち追加」で計測する方針とも整合します。

### 2. 料金をファーストビューに出し、成功報酬0円と上限99万円を明記した

現行LPは料金セクションがページ後半（FAQより下）にあり、「成功報酬0円」の記載がなく、
上限額も表を自分で計算しないと分かりませんでした。隣に「成功報酬33万円〜」の
訴訟プランが並んでいるため、標準プランでも成功報酬を取られるように読める状態でした。

改修版では、ファーストビューに `着手金33万円 / 成功報酬0円 / 最大99万円` の3枚を配置し、
料金セクションを実績・FAQより前に移動しました。

料金表は今回いただいた体系に修正しています（**現行LPの表記とは異なります**）。

| 対応する社数 | 着手金（税込） |
|---|---|
| 1社目 | 33万円 |
| 2社目〜5社目 | 1社あたり 16万5,000円 |
| 6社目以降 | 0円 |
| **上限** | **99万円** |

あわせて、示談金・和解金が弁護士費用とは別であること、実費・訴訟対応が別途であることを
料金表の直下に明記しました。上限額を打ち出す以上ここが曖昧だと、
後の誤解や日弁連の業務広告規程・景表法上の問題につながるためです。

### 3. 解決実績の主役を「0円」から「減額和解」に変えた

現行LPは0円事例が3枚、減額和解が1枚という構成でした。これは、
今回のターゲット選定と逆行します。「0円にできる」を前面に出すと、
遠ざけたい「過剰請求だ、踏み倒したい」層を集め、
「多少の支払いは覚悟している」本来のターゲットには
「0円にならなければ失敗」という誤った期待を与えてしまいます。

改修版では「150万円→50万円・約1ヶ月で和解」を大きく主役に据え、
0円事例は請求根拠に疑問があった事案という文脈を添えて補助的に並べました。
冒頭に「すべての案件が0円になるわけではありません」と明記しています。

**「200万円→0円（名誉毀損・刑事告訴・捜索まで発展）」の事例は削除しました。**
トレント案件ではないうえ、「捜索」という語がこの不安層を過度に怯えさせるためです。
掲載する場合は、トレント案件とは別枠に分けることをおすすめします。

### 4. 「丸投げできる」ことを専用セクションで見せた

「あなたがすること（3項目）」と「弁護士がすること（7項目）」を左右に並べ、
依頼後の役割分担を一目で分かるようにしました。競合サイトの「知識を授けます」型と
最も差がつく部分であり、丸投げ需要への直球の回答になります。

その下に、書類の写真を送ってから弁護士が返信するまでのLINEトーク再現を置きました。
「送ったら何が起こるのか分からない」という不安を消すためのものです。
再現イメージである旨を注記しています。

### 5. 「責めません」を上部に移した

現行LPでは、この層に最も刺さる「反省の気持ちを持ちながらも、法的に妥当な解決を
求めることは正当な権利です」という趣旨のメッセージが、ページ後半の弁護士紹介に
埋もれていました。改修版では2セクション目に独立した枠として配置しています。

なお、匿名相談は不可とのことでしたので「匿名OK」とは書かず、
代わりに守秘義務・家族や勤務先へ連絡しないことを前面に出し、
本人確認が必要である旨を注記しました。

### 6. 情報を増やす導線を絞った

FAQのタブ切り替え（基本／手続き／費用／その他）を廃止し、
不安の大きい順にフラットな9問へ再構成しました。このターゲットはタブを切り替えて探しません。
「家族や職場に知られませんか」「放置したらどうなりますか」「すぐにお金が用意できません」が
上位に来るようにしています。

ヒーローのコラム誘導リンクとナビの「コラム」も外しました。読者を教育するほど
「自分でやろう」に流れるため、今回の戦略ではLPからコラムへの導線は転換の漏れ穴になります。
コラム自体はSEO資産として別途残し、LPからは切り離す想定です。

### 7. 分割払いの記載を実態に合わせた

「3回払いまで対応可能」という現行の記載を、
「ご利用のカード会社の分割払いをご利用いただけます（回数・手数料は各カード会社の規定によります）」
に変更しました。あわせて、流れのステップ3を「着手金のお振込み」から
「着手金のお支払い（カード可）」に修正しています。

## 技術メモ

- Webフォントは使わず端末内蔵の明朝・ゴシックを指定しています。広告LPは表示速度が
  そのまま品質スコアと獲得単価に響くため、外部リクエストをゼロにしています。
  ブランドフォントを厳密に合わせたい場合はGoogle Fontsに差し替えてください。
- FAQとプラン詳細は `<details>` で実装しているため、JavaScriptなしでも開閉します。
- 日本語は語中でも改行されるため、見出しは文節ごとに `inline-block` で包み、
  フォントサイズを `clamp(1.5rem, 6.3vw, 2.45rem)` にして
  「全部やりま／す。」のような割れ方を防いでいます。
- 構造化データ（LegalService）を埋め込んでいます。

### 表示確認済み

Chromium にて 360 / 390 / 430 / 768 / 1024 / 1280 / 1440px の7幅で確認済み。
全幅で横スクロールなし、見出しの文節割れなし、JSエラーなし。
スマホ固定CTAの出入り、JavaScript無効時のLINEボタン動作も確認済みです。

## 今後の検討事項

- ファーストビューの見出しは、広告文言との一致度がクリック後の離脱率に効きます。
  広告見出しが「意見照会書」なら、LP側もその語で受けるパターンを別途用意して
  A/Bテストする価値があります。
- LINE公式アカウントの自動応答に「書類の写真を送ってください。弁護士が確認して
  ◯時間以内にご返信します」を設定しておくと、深夜の流入を取りこぼしません。
- 現行LPにあったコラムは、LPとは別URLでSEO流入の受け皿として維持し、
  コラム側からLPへ送る一方通行の導線にするのが今回の戦略と整合します。
